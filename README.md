# hedefine_doru

**Hedefine Doğru** — YKS (TYT & AYT) Hazırlık, İnteraktif Soru Bankası, Müfredat Ders Kataloğu ve Gerçek Zamanlı Deneme Sınavları Platformu.

## 🚀 Özellikler

- **🎯 Soru Bankası:** Ders ve konu bazlı interaktif soru çözümü, sesli geri bildirim ve detaylı çözümler.
- **📚 Dersler (TYT & AYT Müfredatı):** Tüm TYT ve AYT dersleri, ÖSYM soru kalıpları analizi, KaTeX formül kütüphanesi ve konu bitirme takibi.
- **🏆 Deneme Sınavları:** Gerçek zamanlı geri sayım sayacı, interaktif optik form, net hesabı ($Net = Doğru - Yanlış / 4$) ve tahmini YKS puan karnesi.
- **🔐 Güvenli Auth & DB Mimarisi:** JWT + Refresh Cookie destekli tam teşekküllü kullanıcı kimlik doğrulama sistemi.
- **📱 %100 Mobil Uyumlu:** Akıllı telefonlar için mobil alt navigasyon çubuğu ve duyarlı arayüz tasarımı.

## 🛠️ Kurulum ve Çalıştırma

```bash
# Bağımlılıkları yükleyin
npm install

# Geliştirme sunucusunu başlatın (Frontend + Backend)
npm run dev
```
